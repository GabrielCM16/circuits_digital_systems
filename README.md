# Circuits Digital Systems

## Descrição

Este repositório contém projetos relacionados a sistemas digitais e circuitos lógicos. Aqui, você encontrará simulações, implementações e análises de componentes digitais, como flip-flops, portas lógicas, contadores e outros sistemas eletrônicos digitais.

Feito em VHDL e utilizando o GTKWave para visualização das simulações.
